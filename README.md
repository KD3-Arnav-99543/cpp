# cpp

A collection of C / C++ assignments and practice programs, organized by assignment number.

![C++](https://img.shields.io/badge/C++-90.6%25-00599C?logo=cplusplus&logoColor=white)
![C](https://img.shields.io/badge/C-9.4%25-A8B9CC?logo=c&logoColor=white)

## 📂 Structure

```
cpp/
├── Assignment1/   # Fundamentals — Q1, Q2
├── Assignment2/
├── Assignment3/
├── Assignment4/
├── Assignment5/
```

Each `AssignmentN` folder contains the source files and (where applicable) sample input/output for that set of problems.

## 🛠️ Tech Stack

- **Languages:** C++, C
- **Compiler:** g++ / gcc

## 🚀 Getting Started

Clone the repo:

```bash
git clone https://github.com/KD3-Arnav-99543/cpp.git
cd cpp
```

Compile and run any assignment file, e.g.:

```bash
g++ Assignment1/q1.cpp -o q1
./q1
```
